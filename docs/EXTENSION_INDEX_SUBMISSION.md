# Slicer Extensions Index preparation

The public source repository is
https://github.com/heinjenny95/SlicerLiveSegmentation. It contains the CMake
extension metadata, Apache-2.0 license, citation metadata, contributor guidance,
deterministic release builder, automated tests, and cross-platform CI definition
required for public distribution.

Before submitting to the Slicer Extensions Index:

1. add a 128×128 public icon URL and public screenshot URLs;
2. run the Slicer stable and preview dashboards and review every failure;
3. create the Extensions Index catalog entry using the final immutable repository
   URL and revision;
4. complete institutional privacy, security, and research-software review.

Repository URL and maintainer identity are now grounded in the public GitHub
account. Institutional approval and public visual assets remain publishing-team
responsibilities.
