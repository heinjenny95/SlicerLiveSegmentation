# Security policy

Live Segmentation is research software and is not a certified medical device.
Supported security updates target the latest published release.

Do not disclose credentials, private server addresses, shared-folder paths,
patient information, room data, or project backups in a public issue. Report a
suspected vulnerability privately through GitHub's **Report a vulnerability**
workflow for this repository. Include the affected version, transport mode,
impact, and minimal reproduction steps using synthetic data.

Operational safeguards, trust boundaries, and deployment responsibilities are
documented in [docs/SECURITY.md](docs/SECURITY.md).
